# 民大校园网流量查询工具

输入账号密码，一键查询校园网流量，并**按设备（电脑 / 手机 / iPad…）分别统计**，自动生成可视化报告。

**免安装版：双击 `民大校园网流量查询.exe` 即可，不需要装 Python。**

---

## 一、怎么用（三步）

1. **双击 `民大校园网流量查询.exe`**
   > 首次打开如果 Windows 弹蓝色提示「Windows 已保护你的电脑」：
   > 点 **更多信息** → **仍要运行**。这是因为程序没有购买数字签名证书，不是病毒；出现一次之后不再提示。
2. 填**学号**和**密码**，选统计区间（默认「本月」），点 **开始查询**
3. 首次会弹出验证码输入框（照着图输 4 位字母）——**只需输入一次**；查询完成后自动打开网页报告

> 首次查整月数据需要 10~30 秒，进度条会实时显示。
> ⚠️ 使用前请先连上校园网并完成认证（Wi-Fi 选 `MUC-student`），否则会提示"连不上校园网"。

## 二、报告怎么看

| 区块 | 内容 |
|---|---|
| 概览 | 总流量、会话数、设备数、免费额度（民大 70G）、超支金额估算（1 元/G） |
| **设备流量对比** | 每台设备一张卡片：总流量、占比、会话次数、在线时长、活跃天数、**活跃时段图**、单次流量 Top3 |
| 每日总流量 | 按天柱状图，一眼看出哪天用得多 |
| 明细会话 | 每条会话的时间、设备名、流量、时长、IP（按流量降序） |

## 三、设备名怎么来的

校园网后台只记录 **MAC 地址**，不记录"这是 iPad"，所以需要把 MAC 和你的设备对应起来：

- **方式一（推荐）**：查询完成后程序自动弹出「给设备命名」窗口，列出每台设备的流量，你从下拉框选（电脑 / 手机 / iPad…）或自己输入 → 保存。**只需命名一次**，以后每次自动套用。
- **方式二**：在校园网自助服务平台（zz.muc.edu.cn → 无感知认证）给 MAC 填「备注」，本工具会自动读出来当设备名。
- 没命名的设备会先给个「电脑（推测）」这类提示名，随时可以点主界面 **给设备命名** 改。

> 手机/平板的「私有无线局域网地址」会随机变化，换个网络可能变成新 MAC，到时再命名一次即可。

## 四、常见问题

**Q：提示「连不上校园网」？**
A：先连 `MUC-student` 并完成认证再查询。

**Q：要重新输验证码？**
A：登录状态过期时会再弹一次，输入即可（一般能维持较长时间）。

**Q：想查上个月 / 指定几天？**
A：区间选「自定义」，填起止日期（格式 `YYYY-MM-DD`）；上个自然月直接选「上月」。

**Q：查出来的流量和手机里看的不一样？**
A：校园网计费口径是 **IPv4 下行流量**，不含上行、不含 IPv6。报告"总流量"即计费流量。

**Q：我的账号密码会被保存吗？**
A：**密码不保存**。只把登录后的会话凭据存在本机（`%LOCALAPPDATA%\MUCNetQuery\session.json`，源码版在 `data/`），用于免验证码复用；账号名存在 `config.json`。点主界面「退出登录」可清除。

**Q：怎么彻底卸载？**
A：删除 exe 即可；想清干净数据，再删掉 `%LOCALAPPDATA%\MUCNetQuery` 文件夹。
